# 🚀 YAffiliate

> **Turn Any Product into a Complete Marketing Campaign in Minutes.**

YAffiliate helps affiliate marketers research products, generate complete campaigns, and download ready-to-use marketing assets.

## What YAffiliate Creates

- SEO Article
- Landing Page
- Google Ads
- Email Sequence
- Campaign Summary
- Complete ZIP Package

## How It Works

```text
Search Product
      ↓
Generate Campaign
      ↓
Download Marketing Kit
      ↓
Publish
```

## Local Installation

```powershell
git clone https://github.com/diegoallanalves/yaffiliate.git
cd yaffiliate
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```
